**Apartment Security System**

A robust, modern JavaScript-based application designed to manage and monitor apartment complex security. This system handles visitor logging, resident verification, access control events, and real-time security alerts.



Features:

User Authentication & Roles: Secure login for Administrators, Security Guards, and Residents.

Visitor Management: Track visitor check-ins/check-outs, generate digital entry passes, and maintain historical logs.

Resident Directory: Manage apartment units, owner/tenant details, and registered vehicles.

Real-time Alerts: Instant notifications for unauthorized access attempts or emergency triggers.

Incident Reporting: Digital logbook for guards to report security breaches or maintenance issues.
